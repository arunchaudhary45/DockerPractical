# 🚀 Nginx + Redis Deployment using Docker Compose

This project demonstrates how to deploy a **multi-container application** using **Docker Compose**.

The application includes:
- **Nginx Web Server**
- **Redis Database**
- Both services connected through a **custom Docker network**

---

## 📌 Architecture

User Browser → Nginx Web Server → Redis Database

Both services communicate through a custom Docker network called **appnetwork**.

---

## ⚙️ Technologies Used

- Docker
- Docker Compose
- Nginx
- Redis
